# Submission artifacts

so it is versioned and reviewable rather than living in a browser tab.

## Conventions

- **English**, like every other artifact here. The exception stays what it has
  always been: the composed alert text and the page's interface copy, because
  their readers are residents of Ferreñafe.
- **Every factual claim carries a source or comes out.** Draft prose about a
  real place and a real disaster is the easiest place in this repository to
  assert something plausible and wrong, and the only one where no test will
  catch it.
- **The owner's voice is the owner's.** A draft prepared by an assistant is a
  starting point; first-person claims about the author's life, intent or
  community are rewritten by the author before anything is published.

## What is published, and when

Nothing here is submitted by being committed. A file in this directory is a
draft until the owner publishes it, and the entry below records when that
happened so the repository does not imply more than is true.
